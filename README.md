# Komal Jangir portfolio recreation

This is a responsive, static recreation of the public portfolio page at `https://screenshot-to-sight-871.lovable.app/`.

The public page does not expose its original project source. These files reproduce the visible content, layout, colors, and interactions from the page rather than copying its private Lovable project files.

## Files

- `index.html` contains the portfolio content and semantic page structure.
- `styles.css` contains responsive layouts, theme colors, typography, and decorative artwork.
- `script.js` powers the dark/light theme switch, full-screen navigation, email form handoff, and dismissible badge.

Open `index.html` in a browser to view it. The page uses Google Fonts when an internet connection is available and falls back to local serif and sans-serif fonts otherwise. Submitting the contact form opens a new email draft addressed to the address shown on the reference page.
